# Neuron Demo

Simple demonstrations of CTRNN and Izhikevich neuron models.

## Run

```bash
cd examples/neuron-demo
python demo-ctrnn.py
python demo-iznn.py
```

## Test

These scripts are demonstrations; no separate evolve/test split.

## Task-specific knobs

Parameters are defined directly in the scripts (step size, neuron parameters, simulation length).

## Outputs

- Interactive plots/windows depending on local matplotlib backend.
- Console values where applicable.
