# Signal Tracking (GPU)

Evolves recurrent controllers for signal tracking with optional GPU acceleration.

## Evolve

```bash
cd examples/signal-tracking-gpu
python evolve.py [config_filename] [--cpu-only] [--gpu-only] [--generations N] [--pop-size N] [--seed N]
```

Configs:
- `config-ctrnn`
- `config-ctrnn-anji`

## Test

No separate `test-*.py`; inspect training metrics and winner behavior from outputs.

## Task-specific config knobs

- CTRNN settings and signal/task constants
- GPU/CPU execution flags
- `pop_size`, `fitness_threshold`, `snapshot_interval`

## Outputs

Runtime dir: `exp-<config-filename>/`
- winner genome
- plots/logs generated by evolve script
- snapshots
